## 1. Main Prompt Used in Antigravity

I am a beginner Python student building a college assignment called Agent Gatekeeper for IndiGo Airlines.

Create a beginner-friendly Python Streamlit application that:

- Registers AI agents for customers.
- Allows permitted actions: view fares, book, change and refund.
- Allows agents to be revoked and records the revocation date and time.
- Accepts customer name, agent name, requested action and amount.
- Returns ALLOW, ASK CUSTOMER or BLOCK with a reason and rule number.
- Implements seven security rules.
- Saves agent records and timestamped audit logs.
- Displays my enrolment number, agent registry, audit history and test results.
- Includes the required test cases.
- Uses a clean airline-inspired interface.

Do not automatically execute actual bookings or refunds. ASK CUSTOMER means confirmation is required.
